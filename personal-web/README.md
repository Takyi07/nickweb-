# Nicholas Takyi Turkson: personal website

Black and gold personal site built with HTML, Tailwind CSS and a little vanilla JavaScript.

## Structure

- `index.html` page markup
- `src/input.css` Tailwind source (component classes and custom CSS)
- `tailwind.config.js` colours and fonts
- `css/output.css` compiled stylesheet used by the page
- `js/main.js` mobile menu and footer year
- `assets/` portrait and Kodexx logo

## Edit and rebuild

```bash
npm install
npm run dev      # rebuilds css/output.css while you edit
npm run build    # one-off minified build
```

Open `index.html` in a browser, or publish with GitHub Pages (Settings, Pages, deploy from the `main` branch, root folder).
